## 5. Free Commercial-Use Image Sources

When downloading replacements, use royalty-free licenses that allow commercial use without compulsory attribution:

1. **Unsplash** ([unsplash.com](https://unsplash.com)) - High quality modern workspaces, tech, and authentic corporate photography.
2. **Pexels** ([pexels.com](https://pexels.com)) - Excellent diversity of real people, handshakes, customer support, and workplace shots.
3. **Pixabay** ([pixabay.com](https://pixabay.com)) - Good for industry, manufacturing, and automotive photos.

---

## 6. Implementation Notes

- **File Path:** Place replacement files directly in the `public/` directory with the exact same file name to automatically replace them without changing code.
- **Formats:** Maintain the original extensions (`.jpg` or `.png`), or convert to `.webp` for faster load times.
- **Optimization:** Keep image file sizes between **100 KB - 300 KB** (using tools like Squoosh, TinyPNG, or WebP conversion) to preserve fast page performance.
